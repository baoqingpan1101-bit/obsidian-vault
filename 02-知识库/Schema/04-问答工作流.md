# 问答工作流

> 回答问题时，先查你的维基，再结合我的知识。让你听到的是「你的话」，而不是泛泛而谈。

## 工作流总览

```
[你的问题]
    │
    ▼
① 理解问题 ──── 识别核心主题和关键词
    │
    ▼
② 查询维基 ──── 搜索 Obsidian vault
    │           ├→ 实体页（直接相关）
    │           ├→ 主题索引（背景知识）
    │           ├→ 矛盾记录（相关争议）
    │           └→ 日记/卡片（个人经验）
    │
    ▼
③ 判断情况
    │           ├→ 维基有答案 → 基于维基回答
    │           ├→ 维基有背景 → 维基+补充
    │           └→ 维基空白 → 说明情况，再补充
    │
    ▼
④ 回答 ────────── 整合维基内容 + 自身知识
    │
    ▼
⑤ 检查是否需要更新维基
                ├→ 发现新洞察 → 建议记录
                └→ 发现矛盾 → 建议创建矛盾记录
```

---

## ① 理解问题

**关键词提取**：
- 识别问题中的核心概念
- 提取可能相关的标签/领域
- 判断问题类型（知识查询/实践建议/分析讨论）

**问题类型映射**：
| 类型 | 说明 | 响应策略 |
|------|------|---------|
| 知识查询 | 问「是什么」| 先查维基实体页 |
| 方法咨询 | 问「怎么做」| 先查主题索引+方法卡片 |
| 经验分享 | 问「遇到过吗」| 查日记+卡片 |
| 观点讨论 | 问「你怎么看」| 查矛盾记录+个人思考 |
| 创作生成 | 让我写/做 | 结合维基+能力输出 |

---

## ② 查询维基的优先级（类 GBrain 三层搜索）

| 层级 | 搜索方式 | 适用场景 |
|------|---------|---------|
| **L1 精确匹配** | wikilink 解析 | 已知实体名，直接定位 |
| **L2 全文搜索** | Obsidian 搜索插件（FTS5 级别） | 关键词出现，模糊匹配 |
| **L3 向量语义** | Embeddings（待实现） | 「这个方向有什么」「谁研究过 X」|
| **L4 结构查询** | 标签/日期/状态过滤 | 「所有 🌿成长 状态的实体」「本周更新的」|

> 💡 **与 GBrain 的差异**：GBrain 用 SQLite + FTS5 + 向量共存。你目前用 Obsidian 原生搜索作为 L2，待 Embeddings 实现后升级到 L3。当前阶段优先用好 L1+L2。

```
Obsidian Vault 搜索顺序：

1. 精确匹配
   └→ 直接找到相关实体页/主题索引

2. 相关标签搜索
   └→ 按 tags 模糊匹配

3. 全文搜索
   └→ 搜索关键词在正文中的出现

4. 链接回溯
   └→ 搜索引用了某实体页的其他页面
```

**重点关注**：
- 实体页的「我的思考」区 → 反映你自己的观点
- 矛盾记录的「我的判断」区 → 你已经做出的选择
- 日记中的感悟 → 最近的实践体会
- 卡片盒中的个人注解 → 你标注的重点

## ③ 判断与回答

### 情况A：维基有直接答案
> 直接引用实体页内容回答
> 在回答末尾注明「参考自你的维基：[[实体名]]」

### 情况B：维基有背景知识
> 以维基内容为基础框架
> 补充你没有记录的部分
> 指出你的维基中已有的相关观点

### 情况C：维基几乎空白
> 先说明：「这个问题你的维基里还没有记录」
> 提供通用知识回答
> 主动提出：「要我帮你整理成实体页吗？」

### 情况D：发现矛盾
> 先指出矛盾所在
> 展示不同来源的观点
> 给出我的分析
> 主动提出：「要创建矛盾记录吗？」

## ④ 回答格式规范

### 知识类回答
```markdown
## [回答标题]

根据你的维基[[实体页名称]]：
> [引用维基中的核心定义或观点]

补充说明：
[维基中没有的内容]

---

📚 参考：[[实体页名称]]（你的维基）
```

### 分析讨论类回答
```markdown
## [分析标题]

### 你的已有认知
根据你的维基[[相关实体]]，你之前记录的观点是：
> ...

### 新的视角
[我的补充分析]

### 可能存在的张力
[指出维基观点与新信息的潜在矛盾]

---

💡 建议：如觉得这段分析有价值，我可以帮你更新[[相关实体]]。
```

## ⑤ 主动建议维基更新

**以下情况必须主动建议**：

| 情况 | 建议动作 |
|------|---------|
| 回答中引用了维基外的新洞察 | 建议记录到实体页 |
| 发现与维基已有观点矛盾 | 建议创建矛盾记录 |
| 问题涉及新领域/新概念 | 建议创建新实体页 |
| 分析过程有价值 | 建议整理成卡片 |

**建议话术**：
> 💡 这段分析/洞察和你之前的[[实体页]]有关联，要我帮你更新到维基里吗？
