# 摄取工作流

> 新资料不是「存档」，而是「编译」。LLM 阅读 → 提取 → 整合 → 更新。
>
> **Compiled Truth + Timeline 原则**：Above the line（`我的理解`）收到新资料时 REWRITE；Below the line（`来源引用`、`相关链接`）永远 APPEND，不删除历史。

## 工作流总览

```
[新资料]
    │
    ▼
① 快速浏览 ──── 决定处理深度
    │
    ▼
② 提取 ────────── 摘录核心观点
    │
    ▼
③ 判断 ────────── 分类处理
    │           ├→ 实体页（已有/新建）
    │           ├→ 主题索引（更新）
    │           ├→ 矛盾记录（新建）
    │           └→ 直接归档（不处理）
    │
    ▼
④ 整合 ────────── 更新相关页面
    │
    ▼
⑤ 归档 ────────── 移动到知识库
```

---

## ① 快速浏览（1分钟）

**目标**：判断这条资料值不值得深入处理

**判断标准**：
- 是否提出了**新概念**或**新视角**？
- 是否与你已有的知识**相关或冲突**？
- 是否有**可操作的方法论**？
- 是否**与你当前的问题**直接相关？

**结果**：
- ✅ 值得处理 → 进入第②步
- ❌ 直接归档 → 丢进 `05-剪藏/归档/` 或 `02-知识库/杂项/`

---

## ② 提取（3-5分钟）

**对每条值得处理的资料，记录**：

```markdown
来源：[书名/文章/视频标题]
日期：YYYY-MM-DD
类型：书籍 | 文章 | 播客 | 视频 | 笔记

## 核心观点（3条以内）
1. ...
2. ...

## 最打动我的句子
> ...

## 我的第一反应
> ...

## 关联到已有
- [[实体A]] - 因为...
- [[矛盾记录X]] - 这里可能存在矛盾

## 是否存在矛盾？
- ✅ 是 → 立即创建矛盾记录
- ❌ 否 → 继续

## 处理深度
- 🔵 全面处理 → 创建实体页 + 更新主题索引
- 🟡 部分处理 → 更新现有实体页
- 🔴 轻度处理 → 只摘录关键句子
```

---

## ③ 判断与分类

### 创建/更新实体页的条件
- 资料引入了**新概念**
- 该概念在多个来源中被讨论
- 你需要经常引用这个概念

### 更新主题索引的条件
- 新实体页属于某个已有主题
- 知识结构发生了变化
- 发现了新的子主题

### 创建矛盾记录的条件
- 资料中的观点与已有记录**明显冲突**
- 资料揭示了你之前认知中的**盲点**
- 不同来源对同一问题给出了**不同答案**

## ④ 整合（具体操作）

### 新建实体页
按照 `Schema/00-实体页Schema.md` 格式创建
- Above the line（定义+理解）→ 直接写入
- Below the line（来源引用）→ 首次来源写入

### 更新已有实体页
**关键原则：Above REWRITE，Below APPEND**

- `📖 我的理解` / `📚 来源与引用`（Above）：
  → 收到新资料时 REWRITE，不是追加。重新整合所有来源，形成最新理解。
  → 新资料的引用**替换**旧版本的整合，而不是简单追加一行。
- `🔗 相关实体` / `更新时间`（Below）：
  → APPEND。永远保留历史，不删除。
  → 相关实体链接追加，`updated` 字段改为今天。

### 创建矛盾记录
按照 `Schema/02-矛盾记录Schema.md` 格式创建
确保两方都有公平表述
给出自己的判断和适用边界

### 更新主题索引
- 在对应章节添加新实体链接
- 在「核心资料」添加来源
- 更新「最近更新」日志
- 如有必要，重绘知识树

### 创建矛盾记录
按照 `Schema/02-矛盾记录Schema.md` 格式创建
确保两方都有公平表述
给出自己的判断和适用边界

## ⑤ 归档

| 资料类型 | 归档位置 |
|---------|---------|
| 完整读书笔记 | `03-读书/` |
| 精选摘录 | 对应实体页内嵌 |
| 暂时不处理 | `05-剪藏/收件箱/` |
| 归档参考 | `02-知识库/杂项/` |

---

## 优先级规则

> **时间有限时，优先做这几件事**：

1. 🔴 **创建/更新实体页**（最核心）
2. 🟠 **标记矛盾**（最有长期价值）
3. 🟡 **更新主题索引**（保持结构清晰）
4. 🟢 **完整笔记**（有时间再做）
