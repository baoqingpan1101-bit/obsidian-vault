# 矛盾记录 Schema

> 矛盾是认知的燃料。记录不同观点的冲突，比接受任何一方都更有价值。

## 何时创建矛盾记录

- 两个以上来源对同一问题给出了**不同甚至相反**的答案
- 自己的经验与书本知识**打架**
- 自己的前后观点**发生了变化**
- 读到了「然而」「但是」「尽管如此」这类转折

## 矛盾类型

| 类型 | 说明 | 例子 |
|------|------|------|
| **理论冲突** | 不同理论框架得出的结论矛盾 | A 学派 vs B 学派 |
| **经验 vs 理论** | 实践感受与书本知识不一致 | 工程经验 vs 规范条文 |
| **跨领域矛盾** | 不同领域的常识相互冲突 | 经济学 vs 心理学 |
| **时序矛盾** | 现在的认知与过去的认知矛盾 | 今昔对比，标记认知成长 |
| **表面矛盾** | 字面矛盾但深层一致 | 看似相反实则互补 |

## 必填字段

```yaml
---
id: CON-YYYYMMDD-NNN
title: 矛盾简述
type: 矛盾记录
tags: [矛盾, 领域]
status: 🔥活跃 | 💡已解决 | 🤔待思考
created: YYYY-MM-DD
updated: YYYY-MM-DD
sides: 2  # 冲突方的数量
---
```

## 标准结构

```markdown
# 矛盾标题

## ⚡ 核心冲突
> 用一句话说清楚矛盾是什么。

---

## 🅰️ 观点A：[来源/立场名称]

**来源**：[书名/文章/经验]  
**核心主张**：
> ...
**论据**：
1. ...
2. ...

---

## 🅱️ 观点B：[来源/立场名称]

**来源**：[另一来源]  
**核心主张**：
> ...
**论据**：
1. ...
2. ...

---

## ⚖️ 我的判断

### 分析
> 为什么两边都有道理 / 为什么有一方站不住脚

### 适用边界
> A 更适合什么场景，B 更适合什么场景

### 我的选择
> 在我的实践中，我目前倾向于：
> **...**
> 理由：...

---

## 🔗 相关记录
- [[实体A]] - A 方的理论基础
- [[实体B]] - B 方的理论基础
- [[另一个矛盾记录]] - 相关的矛盾

---

## 📌 更新日志
- YYYY-MM-DD：首次记录
- YYYY-MM-DD：[变化说明]
```

## 命名规范

- 文件名：`矛盾-主题-关键词.md`
- ID 格式：`CON-YYYYMMDD-NNN`
- 标签固定包含 `矛盾`

## 维护规则

1. **不急于解决** — 记录矛盾比强行统一更有价值
2. **定期回顾** — 「时序矛盾」类型要标记认知成长
3. **跨域连接** — 把相关矛盾串起来能看到更大的认知地图
4. **行动导向** — 最终要落实到「我的实践中我倾向于...」
