# 每日简报 Skill

> 每天开始工作前，用 3 分钟了解：你的知识库发生了什么，你关注的事情进展如何。

## 简报维度

```
┌─────────────────────────────────────────┐
│           📋 每日简报 YYYY-MM-DD          │
├─────────────────────────────────────────┤
│ 🏗️ 项目进展   今天在做什么                  │
│ 📚 知识成长   今天学到了什么                 │
│ 🔗 知识关联   发现了什么新联系               │
│ 📅 近期关注   哪些事情需要跟进               │
│ 💡 洞察     有价值的想法值得记录             │
└─────────────────────────────────────────┘
```

## 数据来源

| 来源 | 位置 | 内容 |
|------|------|------|
| 日记 | `20-日志/日记/2026/03/YYYY-MM-DD.md` | 当天感悟、阅读、项目动态 |
| 记账 | `03-领域/财务规划/记账/YYYY-MM 账单.md` | 财务状况 |
| 实体页更新 | Obsidian vault | 最近更新的实体页 |
| 待办 | 日记/笔记 | 标记为 `[ ]` 的行动项 |
| EvoMap | 记忆文件 | 节点状态、任务进展 |

## 编译流程

### ① 读取今日日记

```markdown
## 今日日记必读部分
- 「今天」：今天做了什么
- 「感悟」：今天的思考
- 「阅读」：今天读了什么
```

### ② 检查知识库变化

**最近更新（24小时内）**：
- 哪些实体页被更新了
- 新增了哪些页面
- 是否有矛盾记录被创建

**孤立/过时的警告页面**：
- 上次维护报告标记的页面

### ③ 项目状态汇总

从相关实体页读取：

```
岩土工程AI辅助写作系统
  - 状态：🌿成长
  - 最新进展：[从日记/笔记中提取]
  - 下一步：[从实体页「我的思考」中提取]
```

### ④ 生成行动建议

- 日记中未完成的事项
- 本周到期的事项
- 知识库待维护项

## 触发方式

1. **你说「给我一个简报」** → 生成今日简报
2. **每天早上** → 可以设定自动化（可选）
3. **日记前** → 简报可以帮助你回顾昨天

## 限制与注意事项

- **不要自动生成** — 除非你明确要求，否则不会每天自动跑
- **数据新鲜度** — 简报基于你已有的日记和笔记，空白的日记 = 空白的内容
- **不要追求完美** — 简报是导航工具，不是表演作品。有多少读多少。
