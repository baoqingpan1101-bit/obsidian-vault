# 主题索引 Schema

> 主题索引是知识库的「目录」。它把散落的实体页和笔记按主题归类，形成一张网。

## 何时创建主题索引

- 一个主题下有 3+ 个实体页
- 你想从宏观上把握某个领域的知识结构
- 某个项目/领域需要总览视图

## 必填字段

```yaml
---
id: IDX-YYYYMMDD-NNN
title: 主题名称
type: 主题索引
tags: [主题, 领域]
related_domains: []  # 相关领域
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

# 主题名称

> 一句话描述这个主题的核心价值。
```

## 标准结构（Compiled Truth + Timeline 架构）

```
Above the line（Compiled Truth）：
  - 主题定义
  - 知识结构（核心理论/方法论/工具）
  - 活跃问题
  ↓ 新资料到达时 REWRITE
Below the line（Timeline / Append-only）：
  - 核心资料（追加引用）
  - 最近更新（追加）
  - 我的关注点
  ↓ 追加记录，保持历史可追溯
```

## 标准结构

```markdown
# 主题名称

## 🎯 主题定义
> 这个主题研究/关注的是什么。

---

## 📐 知识结构

### 核心理论/概念
- [[实体A]] - 简短说明
- [[实体B]]

### 方法论
- [[方法1]] - 适用场景
- [[方法2]]

### 工具/资源
- [[工具1]]
- [[工具2]]

---

## 🌳 知识树

```
主题
├── 子主题A
│   ├── 实体X
│   └── 实体Y
└── 子主题B
    ├── 实体Z
    └── ...
```

---

## 📖 核心资料
- [[资料A]] - 为什么重要
- [[资料B]]

---

## 🔥 活跃问题
> 目前还未解决或有争议的问题
- 问题1：...
- 问题2：...

---

## 📝 最近更新
- YYYY-MM-DD：[[实体X]] 新增
- YYYY-MM-DD：[[主题Y]] 更新了...

---

## 💭 我的关注点
> 这个主题中你最感兴趣或最需要深入的方向
```

## 命名规范

- 文件名：`XX-主题名称.md`（带序号便于排序）
- ID 格式：`IDX-YYYYMMDD-NNN`
- 子主题用 `├──` 和 `└──` 树形表示
