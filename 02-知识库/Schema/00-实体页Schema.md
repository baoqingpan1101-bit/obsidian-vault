# 实体页 Schema

> 实体页是知识库的「词条」。每个核心概念、项目、人物都应有自己的一张卡片。

## 何时创建实体页

- 一个概念在 2 篇以上资料中被讨论
- 一个项目/系统有多个组成部分
- 一个主题跨越多个领域
- 你发现自己反复引用某个主题

## 必填字段

```yaml
---
id: ENT-YYYYMMDD-NNN  # 唯一ID，如 ENT-20260405-001
title: 实体名称
type: 实体页
tags: [标签1, 标签2]
status: 🌿成长 | 🔒稳定 | ⚠️待验证
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: 3  # 引用此实体的资料数量
cross_refs:  # 相关实体（手动维护）
  - [[实体A]]
  - [[实体B]]
---
```

## 标准结构（Compiled Truth + Timeline 架构）

```
Above the line（Compiled Truth）：
  - 一句话定义
  - 我的理解
  - 来源与引用
  ↓ 不变部分，新资料到达时 REWRITE
Below the line（Timeline / Append-only）：
  - 相关链接（[[wikilinks]]）
  - 更新日志（仅追加，不修改历史）
  ↓ 追加部分，永不重写历史
```

## 标准结构

```markdown
# 实体名称

## 💡 一句话定义
> 用自己的话写，不超过一句话。

---

## 📖 我的理解
### 核心要点（3-5条）
1. ...
2. ...

### 我的类比/例子
...

---

## 📚 来源与引用
- [[书名/文章名]] - 核心观点摘录
- [[另一来源]] - 不同角度

---

## 🔗 相关实体
- [[相关概念A]] - 关联说明
- [[相关概念B]]

---

## ⚡ 矛盾/争议（如果有）
> 不同来源的冲突观点
- 来源A认为：...
- 来源B认为：...
- 我的判断：...

---

## 🤔 我的思考
在这里写下你自己的分析和见解。
```

## 命名规范

- 文件名：`实体名称.md`（简洁、无特殊字符）
- ID 格式：`ENT-YYYYMMDD-NNN`
- 链接语法：`[[实体名称]]`

## 维护规则

1. **更新时修改 `updated` 字段**
2. **每引用一次 sources +1**
3. **发现矛盾立即记录到「矛盾/争议」区**
4. **定期检查孤立页面并补充链接**
