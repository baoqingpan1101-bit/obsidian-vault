# AI 知识库使用指南

## 简介
这是一个 AI 辅助的 Obsidian 知识库，使用 OpenCode 连接讯飞 Coding Plan API。

## 快速开始

### 1. 启动 OpenCode
在终端运行：
```bash
opencode
```

### 2. 使用 AI 功能
在 Obsidian 中，你可以：
- 让 AI 整理笔记
- 查询知识库内容
- 采集网络内容

### 3. 常用命令
- `/ingest` - 整理 raw/ 目录的原始素材
- `/query <问题>` - 查询知识库
- `/lint` - 整理和修复笔记格式

## 配置
- AI Provider: 讯飞星辰 Coding Plan
- Model: astron-code-latest
- API: https://maas-coding-api.cn-huabei-1.xf-yun.com/v2

## 目录结构
```
AI_Knowledge_Base/
├── AGENTS.md          # AI 行为规则
├── AI_CONFIG.md       # AI 配置
├── raw/               # 原始素材（AI 只读）
├── wiki/              # AI 维护的笔记
└── assets/            # 图片和附件
```
