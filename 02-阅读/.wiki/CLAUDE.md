## 📚 知识库结构

### 三层架构

```
原始资料层 (F:\电子书)
    ↓ AI摄取
Wiki层 (Obsidian: 02-阅读/.wiki/)
    ↓
应用层 (阅读笔记、书单、感悟)
```

### 目录分类

| 目录 | 用途 |
|------|------|
| `书籍/文学经典` | 中外小说、散文、诗歌 |
| `书籍/历史社科` | 历史著作、社会学、心理学 |
| `书籍/专业技术` | 技术书籍、专业教材 |
| `书籍/官场社会` | 官场小说、社会现实主义 |
| `书籍/悬疑推理` | 推理、悬疑、惊悚 |
| `书籍/国学经典` | 国学古籍、经典译著 |
| `书单` | 主题书单、推荐列表 |
| `阅读笔记` | 读书笔记、读后感 |
| `.wiki` | Wiki系统文件 (index.md, log.md) |

## 🔄 工作流程

### 1. 摄入流程 (Ingest)

```
1. 扫描 F:\电子书
2. 识别新文件
3. 生成元数据卡片 → 对应分类目录
4. 更新 index.md
5. 记录到 log.md
```

### 2. 查询流程 (Query)

```
1. 用户提问
2. 搜索 index.md 定位相关书籍
3. 读取相关笔记
4. 综合回答
5. 有价值的回答 → 新建笔记保存
```

### 3. 检查流程 (Check)

```
每月检查:
- 是否有过时内容
- 是否有矛盾信息
- 是否有关联书籍未链接
- 是否有遗漏的重要摘录
```

## 📋 标签系统

### 书籍状态
- `#to-read` - 想读
- `#reading` - 在读
- `#read` - 已读

### 书籍类型
- `#文学` `#历史` `#社科` `#技术` `#哲学`
- `#心理学` `#经济` `#政治` `#小说` `#散文`

### 书籍评价
- `#极力推荐` `#值得一读` `#一般` `#不推荐`

---

## 🎯 质量标准

1. **元数据完整**: 至少包含 title, author, category, status
2. **关联链接**: 每本书至少链接 2 本相关书籍
3. **个人印记**: 有真实的阅读感受和摘录
4. **定期更新**: 已读书籍应在读完后一周内完成笔记

---

## 🤖 AI 使用指南

当用户要求：
- "帮我找一本关于XX的书" → 搜索 index.md
- "推荐几本书" → 参考书单目录 + 个人评价
- "这本书讲了什么" → 读取对应笔记
- "我想了解XX领域" → 综合多本书籍形成概述
