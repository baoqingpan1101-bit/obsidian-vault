# 见路不走 · 实践笔记

## 模板说明
每次遇到"我在套用别人经验但条件不符"的决策场景时，新建一条记录。
不需要写完整，关键是记下当时的判断过程。

---

## 记录模板

### 场景
（一句话描述当时面临的决策或选择）

### 我原本打算怎么做
（套用的是谁的经验/路径？为什么觉得可以照搬？）

### 条件对比
| 项目 | 他的条件 | 我的条件 |
|------|----------|----------|
|      |          |          |

### 发现了什么不符
（哪个关键"因"我不具备？）

### 实际怎么做的
（见路不走之后，找到的自己的因果链是什么？）

### 结果与复盘
（事后验证：判断对了吗？下次遇到类似场景怎么调整？）
